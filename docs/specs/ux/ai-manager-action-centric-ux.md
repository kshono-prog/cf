# AI Manager Action-Centric UX 仕様

## 北極星コンセプト

> **「AIマネージャーが、次の一手を出し、クリエイターはその場で完了する」**

現在の設定中心 UI を段階的に行動中心 UI へ移行する。
クリエイターが「何をすればよいか迷う」体験を排除し、
「AIに言われたことをその場でやったら、自分もページも育っていた」を実現する。

---

## プロダクト価値仮説

| 仮説 | 期待効果 |
|---|---|
| 迷いの削減 | 継続率 UP |
| 小さな成功体験の連続 | 抵抗感 DOWN |
| 進捗可視化 | 自己効力感 UP |
| 応援可視化 | 活動継続の動機 UP |
| 信頼スコア向上 | ファン / 仕事機会 UP |

---

## 体験フロー概要

### A. ホームに「AIマネージャーを呼ぶ」固定 CTA

押すたびに「今の優先タスク Top3」を表示する。
各タスクには以下を必ず付与する：

- **目的**（なぜ今やるか）
- **所要時間**（2 分 / 5 分 / 10 分）
- **完了後の効果**（何が伸びるか）
- **「この場でやる」ボタン**

### B. その場完結「インライン実行」

画面遷移を最小化。モーダル / サイドパネルで完結させる。

- 入力補助（テンプレート / AI 下書き）
- 1 アクションで保存・公開
- 完了後に即フィードバック（「信頼度 +2」「プロフィール充実度 +5%」など）

### C. 完了演出（ゲーム感）

- XP / レベル / バッジ
- 連続達成ストリーク（日次・週次）
- 「次に解放される機能」の告知
- 「今日の成果カード」自動生成（SNS 共有可）

---

## タスク設計フレーム（迷わせないためのルール）

各タスクは以下のメタ情報を持つ：

| メタ情報 | 内容 |
|---|---|
| 優先度 | Impact × Urgency |
| 所要時間 | 2 分 / 5 分 / 10 分 |
| 難易度 | ★1〜3 |
| カテゴリ | 成長 / 信頼 / 収益 / 関係性 |
| 前提条件 | 未設定項目など |
| 成果指標 | 完了で何が伸びるか |

### ユーザーフェーズ別 優先ロジック

| フェーズ | 優先タスク |
|---|---|
| 初期ユーザー | 迷い削減タスク（プロフィール / 初投稿） |
| 活動中ユーザー | 関係性タスク（お礼 / 近況共有） |
| 停滞ユーザー | 最小行動タスク（1 分で終わる再起動タスク） |

---

## 成長メーター（5 軸）

| 軸 | 意味 |
|---|---|
| Creator Skill | 発信力・継続力 |
| Page Growth | ページ完成度 |
| Trust | 信頼・信用 |
| Fan Energy | 応援熱量 |
| Opportunity | 仕事接続可能性 |

タスク完了で複数メーターが少しずつ上昇。
「何をすると何が伸びるか」を明示して行動学習を促進する。

### 機能解放型 進行

| レベル | 解放機能 |
|---|---|
| 2 | 投稿テンプレ拡張 |
| 3 | AI 自動提案精度 UP |
| 4 | サポーター分析解放 |
| 5 | 仕事機会接続機能解放 |

---

## 設定画面の段階的非表示方針

| Phase | 施策 |
|---|---|
| Phase 1 | 設定は残すが導線を弱める |
| Phase 2 | AI タスク内で必要な設定だけ都度表示（Just-in-time） |
| Phase 3 | 詳細設定は「上級者メニュー」に格納 |

→ 「最初から全部設定」をなくし、必要な瞬間に必要な設定だけ表示する。

---

## ファン応援の可視化

- **応援タイムライン**（誰がいつ何に共感したか）
- **応援ヒートマップ**（曜日 / 時間帯）
- **「今週の応援ハイライト」自動要約**
- **お礼アクションの提案**（ワンタップ送信）

数字だけでなく「意味」を返す。
例：「この投稿は"制作裏話"に反応が集中しています。」

---

## 仕事接続（クリエイターの最終価値）

- 実績カード自動生成（活動継続 / 応援推移 / 達成タスク）
- コラボ依頼を受けるための「信頼プロフィール」整備
- AI が案件応募文を下書き（過去実績を引用）
- 「今月の活動レポート PDF」ワンクリック出力

---

## MVP スコープ（最短価値検証）

最初の検証はこの 4 つだけで行う：

1. **AIマネージャーボタン**（Top3 タスク表示）
2. **タスクのその場完結 UI**（最低 2 種類）
3. **完了時の成長フィードバック**（XP + 信頼度）
4. **週間サマリー**（何を達成し何が伸びたか）

これだけで「迷わない」「進める」「成長が見える」を検証可能。

## 設計上の制約・前提

- AI は提案する。人間が決定する（既存方針を維持）
- 資金移動・配分・ブリッジの自動実行は追加しない
- 既存 `AgentTask` フローと整合を取る
- Prisma schema 変更・新規 env var は事前承認が必要
