## アイデア集

### 1. Impact Numbers（インパクト数字のシンプル強調）

**概要**: 投稿数・支援者数・活動継続月数を大きな数字で並べて表示する。

```
┌──────────┬──────────┬──────────┐
│   347    │    28    │   18ヶ月 │
│ 投稿本数  │ 支援者数  │ 活動継続  │
└──────────┴──────────┴──────────┘
```

**使用データ**: `Post`（投稿数）、`Contribution`（支援者数）、`CreatorActivityCredibility`（activeMonths）
**スキーマ変更**: 不要
**伝わること**: 実績の重さを一瞬で。数字が行動の証明になる。
**実装コスト**: 低
**推奨度**: ⭐⭐⭐⭐⭐

---

### 2. Living Funding Pulse（リアルタイム感のある進捗）

**概要**: 静的なゲージではなく、最近の支援者名（匿名可）を添えて「動いている感」を演出する。

```
┌─────────────────────────────────────────┐
│  Guitar Album Project                   │
│                                         │
│  ████████████████░░░░░░░  68%          │
│                                         │
│  ¥340,000 / ¥500,000                   │
│  残り ¥160,000 · 24人が支援中          │
│                                         │
│  最近: yukiさん、taroさん、他2人        │
└─────────────────────────────────────────┘
```

**使用データ**: `Goal`、`Contribution`（最近の支援者 displayName / 匿名フラグ）
**スキーマ変更**: 不要（匿名フラグが未実装なら要追加）
**伝わること**: 動いているプロジェクト感、社会的証明。
**実装コスト**: 低
**推奨度**: ⭐⭐⭐⭐⭐

---

### 3. Creator Voice Card（本人コメント付きプロジェクトカード）

**概要**: プロジェクト説明や最新投稿の冒頭をクォートスタイルで引用し、数字より先に人間のストーリーを見せる。

```
┌─────────────────────────────────────────┐
│  "ギターで語れることを、録音に残したい。  │
│   スタジオ代が一番の壁でした。"          │
│                                  ─ Kenji│
│                                         │
│  Album Recording Project                │
│  ████████████████░░░  68% 達成中        │
└─────────────────────────────────────────┘
```

**使用データ**: `Project.description` または最新 `Post.body` の冒頭 N 文字
**スキーマ変更**: 不要
**伝わること**: 人間のストーリーが先に来る。数字は後。
**実装コスト**: 低
**推奨度**: ⭐⭐⭐⭐

---

### 4. Activity Heatmap（GitHub スタイルの投稿ヒートマップ）

**概要**: 投稿頻度を週×月のグリッドで表示。継続性を可視化する。

```
Jan  ░░░░▒░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
Feb  ░▒▒░░░░░░░░░░░▒░░░░░░░░░░░░░░░░░░░░░░░░
Mar  ▓▓▓▓▓▓▓▓▒▒▒▒▒▒▒▒▒▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░
```

**使用データ**: `Post.publishedAt`（週ごとに集計）
**スキーマ変更**: 不要
**伝わること**: 習慣として続けている、という可視化。「この人は本気だ」と伝わる。
**実装コスト**: 中（集計 + SVG/グリッド描画）
**推奨度**: ⭐⭐⭐⭐

---

### 5. Supporter Wall（支援者の壁）

**概要**: 支援者のアバター/イニシャルアイコンをグリッド状に並べる（匿名オプション付き）。

```
このプロジェクトを信じた人たち

[avatar] [avatar] [avatar] [avatar] [avatar]
[avatar] [avatar] [avatar] [avatar]  +14人
```

**使用データ**: `Contribution` → `Supporter`（avatarUrl / displayName）
**スキーマ変更**: 不要（匿名フラグが未実装なら要追加）
**伝わること**: コミュニティが存在する、という可視化。
**実装コスト**: 中
**推奨度**: ⭐⭐⭐⭐

---

### 6. Next Goal Reveal（目標の次ステップ予告）

**概要**: 現在のゴール達成後に何が起きるかを明示し、「今支援する意味」を伝える。達成時期を推定表示。

```
─────────── NEXT ─────────────────────────
📀 Mini Album リリース

このゴール達成後、音源を全支援者に届けます。
現在のペースで達成まで 約2ヶ月。

[ 応援する → ]
```

**使用データ**: `Goal`（targetAmount / confirmedAmount）、`Contribution`（月次ペース計算）、`Project.description`
**スキーマ変更**: 不要（「達成後の約束」フィールドがあると尚良い）
**伝わること**: 「今支援する意味」が明確になる。CTA との連携が強い。
**実装コスト**: 中
**推奨度**: ⭐⭐⭐⭐

---

### 7. Micro-testimonials（支援者の一言コメント）

**概要**: 支援時のメッセージを承認制でカード表示。匿名オプション付き。

```
"ライブを見てから気になってました。
 応援しています！"

"ギタリストとして共感。続けてほしい。"
```

**使用データ**: `Contribution.message`（要フィールド追加 or 別テーブル）
**スキーマ変更**: `Contribution` に `message` / `isPublic` フィールド追加が必要
**伝わること**: 見知らぬ人の言葉が最も強い社会的証明になる。
**実装コスト**: 中（スキーマ変更込み）
**推奨度**: ⭐⭐⭐⭐⭐（スキーマ承認後）

---

### 8. Creator Chronicle（活動の軌跡タイムライン）

**概要**: ステージ昇格・ゴール達成・最初の支援者など、マイルストーンをタイムラインで表示。

```
─── 2024年4月 ───────────────────────────
  最初の投稿

─── 2024年9月 ───────────────────────────
  EARLY へ昇格 / 初ゴール達成（¥50,000）

─── 2025年3月 ───────────────────────────
  EMERGING へ昇格
```

**使用データ**: `Post`（初投稿日）、`Contribution`（初支援日）、`Goal`（達成日）、`CreatorStage`（昇格履歴 — 現状は派生値のみ）
**スキーマ変更**: ステージ昇格履歴を永続化するなら要追加
**伝わること**: このクリエイターは続けている人だ、という信頼感。
**実装コスト**: 高
**推奨度**: ⭐⭐⭐

## 推奨実装ロードマップ

### 即時（スキーマ変更なし）
1. **Impact Numbers** — 既存データで完結。最小コストで最大訴求。
2. **Creator Voice Card** — Project.description を引用するだけ。ストーリー訴求。
3. **Living Funding Pulse** — 進捗バーに支援者名を添える。社会的証明。

### 短期（スキーマ変更承認後）
4. **Micro-testimonials** — `Contribution.message` + `isPublic` フィールド追加。
5. **Supporter Wall** — 上記と合わせて匿名フラグを設計。

### 中期
6. **Activity Heatmap** — 集計 + グリッド UI。
7. **Next Goal Reveal** — ゴールの「約束」フィールドと達成時期推定。
8. **Creator Chronicle** — ステージ昇格履歴の永続化設計とともに。
