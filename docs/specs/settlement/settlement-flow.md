# Settlement Flow

## 目的

Project に紐づく資金フローを、安全に `達成 -> bridge -> 配分` まで扱う。

## 基本フロー

1. Contribution が蓄積される
2. Goal 達成判定を行う
3. 必要に応じて bridge を記録または確認する
4. 配分 plan を作る
5. distribution 実行結果を保存する

## 安全原則

- 金銭移動に関する変更は常に高リスクとして扱う
- AI が勝手に最終実行判断をしない
- 記録と監査ログを必ず残す
- 自動化は確認と補助に限定する

## v1 の AI 活用範囲

- 状態整理
- 異常検知
- 次アクション提案
- レポート作成

## v1 で AI に任せない範囲

- 自動送金判断
- 自動 bridge 実行
- 自動 distribution 実行
