# Task

MVP と beta 機能境界の固定

## Goal

今ユーザーに見せる本命機能と、実験扱いにする機能の境界を文書と導線で明確にする。

## Scope

- MVP に含める機能を確定する
- beta 扱いの機能を確定する
- roadmap / project state / readme の整合を取る
- 今後 UI で分離すべき対象を洗い出す

## Non-Goals

- 画面実装の全面変更
- beta 機能の削除

## Files Likely Affected

- `PROJECT_STATE.md`
- `docs/roadmap/backlog.md`
- `docs/roadmap/vision.md`
- `README.md`

## Acceptance Criteria

- MVP の定義が文書で一貫している
- beta 領域が明文化されている
- 4週間の優先順が文書化されている

## Risks

- 将来やりたいことを削ったように見えて迷いが出る
- README だけ古いまま残る可能性

## Validation

- 関連 docs の読み合わせ
- MVP / beta の分類に矛盾がないか確認

## Result

- `PROJECT_STATE.md` を更新
- `docs/roadmap/backlog.md` を更新
- `docs/roadmap/vision.md` を更新
- `README.md` を更新
