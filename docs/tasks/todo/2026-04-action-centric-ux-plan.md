## フェーズ別スケジュール（目安）

### MVP（4月）
```
UX-1 → UX-2
```
- AIマネージャーボタンで Top3 表示
- 最低 2 種類のインライン完結 UI
- 完了後フィードバック（テキストのみ）
- **検証指標**: ボタン押下率 / タスク完了率 / 24h 内完了数

### Phase 2（5〜6月）
```
UX-3, UX-4, UX-5（並行可）
```
- XP / ストリーク / 成長メーター（derived 値）
- ファン応援タイムライン・ヒートマップ
- 設定導線を弱め、CTA を昇格
- **検証指標**: 7 日継続率 / 設定画面訪問率（↓）/ 応援アクション増加率

### Phase 3（7月以降）
```
UX-6
```
- 実績カード・信頼プロフィール
- AI 案件応募文下書き
- 月次活動レポート
- **検証指標**: 仕事接続アクション数

## 制約（変えないもの）

- AI は提案のみ。実行・承認は人間が行う
- 資金移動・配分・ブリッジの自動実行は追加しない
- 高リスク領域（settlement / bridge / distribution）の UX 変更は別承認
- Prisma schema 追加は事前承認が必要
- `1 Issue = 1 PR` を厳守
