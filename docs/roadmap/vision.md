# Vision

## 北極星

クリエイターの活動運営を支える `AI事務所` を作る。

AIがやること:

- 活動状況を集める
- 支援状況を整理する
- 次にやるべきことを提案する
- 投稿案、告知案、レポート案を下書きする
- 承認後に低リスク業務を実行する

人がやること:

- 方針決定
- 最終承認
- 対外責任を持つ判断

## 1年後の到達イメージ

- 1人のクリエイターが週1回以上使う
- 週次レポート、投稿案、告知案、お礼文案が出せる
- `AgentTask` で提案から承認まで回る
- 低リスクな定常業務だけ半自動で回る
- 支援と活動の状況が同じ管理画面で確認できる

## プロダクト原則

1. 完全自動ではなく `承認付き半自動`
2. 汎用AIではなく `クリエイター運営特化`
3. モデル性能差ではなく `運営フローと履歴` で勝つ
4. お金まわりは最後まで慎重に扱う
5. 実験機能は本命導線に混ぜすぎない

## 現時点の本命価値

- Public profile
- Project / Goal / Contribution
- Settlement / Distribution
- AI task による運営補助

## 現時点でまだ本命にしないもの

- 完全自動投稿
- 完全自動意思決定
- オンチェーン自動執行の拡張
- 多業種展開
