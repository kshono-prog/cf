# Creator Founding Roadmap

## 3-1. ロードマップの前提

AIの進化は速い。
エージェント基盤、長文脈、ツール接続、要約、比較、マルチモーダル理解は今後さらに改善する可能性が高い。

したがって、Creator Founding の戦略は、

> **いまのAIに無理をさせて完成形を固定すること**ではなく、
> **将来のAI進化で価値が加速度的に高まる土台を先に作ること**

であるべきだ。

そのため、ロードマップは
**今すぐ作るべきもの**
**軽く作るべきもの**
**まだ重く作らないもの**
を分けて考える。

## 3-2. 今すぐ作るべきもの

### 1. Vision / Constitution / Role の固定

プロジェクトの判断基準を明文化し、ぶれない軸を作る。

### 2. Activity Log 基盤

すべての行動履歴を残す基盤を作る。

対象:

- Project 更新
- Goal 更新
- 会議
- タスク
- 応募
- 営業
- 支援者対応
- 協業履歴
- Manager Note
- AI提案採否

### 3. Manager Assignment

誰が誰を担当するかを明確にする。

### 4. Manager Note

人間にしか取れない現場文脈を記録する。

### 5. External Contact

会場、主催者、営業先、メディア、ブランドなどの接点を管理する。

### 6. Creator Home

Creator の事務所ホーム画面を整える。

### 7. Manager Desk

Manager が複数の Creator を支えられる運営画面を整える。

## 3-3. 軽く作るべきもの

### 1. Daily Briefing

AIが今日の要点をまとめる。

### 2. Meeting Support

会議アジェンダ、議事録、決定事項整理。

### 3. Task Suggestion

次にやるべきことの提案。

### 4. Draft Generation

投稿、応募、営業文面、企画書の下書き。

### 5. Weekly Summary / Reflection

週次の振り返りと次週の提案。

これらは今でも価値があり、AI進化でそのまま強化される。

## 3-4. まだ重く作らないもの

### 1. 完全自律営業

AIが勝手に営業し続けるような設計は、現時点では固定しすぎない。

### 2. AI依存の単一評価

作品や人気の最終評価を AI 単独に依存しない。

### 3. Marketplace の全面展開

Venue / Media / Collaborator / Opportunity Provider をいきなり巨大市場として作り込まない。

### 4. 独自モデル前提の設計

モデルそのものを握りに行くより、外部進化を活かせる基盤を優先する。

## 3-5. フェーズ別ロードマップ

### Phase 0: 定義

- Vision 固定
- Constitution 固定
- Creator / Manager / AI Office の役割固定
- Stage / Trust / Skill の骨子整理

- Creator Home
- Manager Desk
- Manager Assignment
- Manager Note
- External Contact

### Phase 2: AI補助の導入

### Phase 3: Trust / Stage / Skill 基盤

- Stage Map
- Skill Map

- Missing Items Tracker

- Supporter CRM
- Opportunity CRM
- External Contact pipeline

- Collaborator
- Venue

- より高度な半自動運営
- 対外先ごとの提案最適化
- マルチモーダル現場支援
- 深い文脈理解に基づく Manager Copilot

## 3-6. 90日 / 180日 / 12か月の優先整理

### 90日

- Vision / Constitution 固定
- Creator / Manager / AI Office の役割明文化
- Manager Assignment / Manager Note / External Contact の設計
- Creator Home / Manager Desk のUI要件定義
- Action Log 実装方針の決定

### 180日

- Creator Home 実装
- Manager Desk 実装
- Meeting / Planner 最小版
- Daily Briefing
- 要約 / タスク抽出
- CRM 最小版
- Stage / Skill / Trust の骨子導入

### 12か月

- Business Layer 最小版
- Supporter CRM / Opportunity CRM 強化
- Collaborator / Venue / Media の導入
- Missing Items Tracker
- Discovery / Recommendation の初版
- AI補助の高度化

## 3-7. このロードマップの基本戦略

Creator Founding は、いま全部を実現しようとしない。
代わりに、

1. **制度を決める**
2. **履歴を集める**
3. **人間が使える運営OSを作る**
4. **AIは補助から入れる**
5. **AIの進化で後から一気に伸びる構造にする**

という順番で進む。

これが、最小構成で最大効果を得るための最も現実的で強い戦略である。

## 4. 最終宣言

Creator Founding は、

> **すべての人に開かれ、
> 信頼を積み上げた人に、より深い支援とより大きな機会が返り、
> Creator・Manager・AI Office を核として、
> 創る人、支える人、運営する人がともに成長できる
> 創作活動の事務所基盤 / 創作経済圏の中核**
>
> **を目指す。**

このプロジェクトの本質は、
便利な機能を増やすことではない。

**創作を一人で抱え込まなくてよい世界をつくること**である。
