# DEC-001 Product Scope

日付: 2026-03-07

## 決定

このプロジェクトの当面の中核を `クリエイター向けAI事務所` とする。

## 採用内容

- Public profile / Project / Goal / Contribution は本命領域とする
- Settlement / Distribution も本命領域として維持する
- AI Office は実験ではなく将来中核になるが、現時点では `承認付き半自動` に限定する

## 却下した方向

- 単なる投げ銭 UI に戻す
- 完全自律 AI 運営を先に作る
- 多業種向け汎用運営ツールに広げる

## 理由

- 既存実装がすでにその方向を向いている
- 個人開発では特化の方が勝ちやすい
- 完全自動は責任境界が重すぎる
