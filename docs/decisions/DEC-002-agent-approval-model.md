# DEC-002 Agent Approval Model

日付: 2026-03-07

## 決定

AIエージェントもプロダクト内 AI task も、基本は `承認付き半自動` で運用する。

## 自動で進めてよい範囲

- 仕様内の実装
- リファクタ
- テスト追加
- docs 更新
- 低リスクな内部 task 起票

## 承認が必要な範囲

- schema / migration 変更
- env var 追加
- 依存追加
- 外部公開内容の最終反映
- 送金 / 配分 / bridge 関連の仕様変更

## 理由

- 個人開発で完全自動の監視は難しい
- 誤実行コストが高い
- 監査可能な履歴を残しやすい
